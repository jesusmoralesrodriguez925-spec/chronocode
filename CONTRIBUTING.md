# Contribuyendo a ChronoCode

¡Gracias por tu interés en mejorar ChronoCode! Como proyecto Open Source, las contribuciones de la comunidad son muy bienvenidas.

## ¿Cómo puedo contribuir?

### 1. Reportar un Bug
Si encuentras un error, por favor abre un **Issue** en GitHub. Incluye:
- Una descripción clara del problema.
- Los pasos para reproducirlo.
- El sistema operativo que estás usando (Termux, Windows, Mac, Linux).
- El proveedor de IA que estabas usando (Gemini, Groq, etc.).

### 2. Sugerir una Mejora
Si tienes una idea para una nueva función, abre un **Issue** con la etiqueta `enhancement` y describe tu idea.

### 3. Enviar Código (Pull Request)
1. Haz un **Fork** de este repositorio.
2. Crea una nueva rama para tu función o arreglo: `git checkout -b feature/mi-nueva-funcion`.
3. Escribe tu código (asegúrate de mantener el estilo simple y sin dependencias externas pesadas).
4. Haz un **Commit** con un mensaje claro.
5. Haz **Push** a tu rama y abre un **Pull Request** en este repositorio.

## Estilo de Código
- Mantén el código en un solo archivo (`chronocode_v2.py`) si es posible.
- Usa Python 3.10+.
- Sigue las convenciones de PEP 8.
- No agregues librerías externas a menos que sea estrictamente necesario.

¡Gracias por ayudar a que ChronoCode sea mejor!
